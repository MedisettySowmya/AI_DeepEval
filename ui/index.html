How scoring works

Answer relevancy
The judge splits the answer into statements and checks whether each addresses the original question. Yes and borderline verdicts count toward the score.

Hallucination
The judge checks consistency with reference context. Yes verdicts count toward the score. A high score means agreement with that context; it does not independently verify real-world facts.

For the pinned DeepEval 4.3.1, higher is better. Each metric passes when score ≥ threshold. Missing required data is skipped, never treated as a pass.
